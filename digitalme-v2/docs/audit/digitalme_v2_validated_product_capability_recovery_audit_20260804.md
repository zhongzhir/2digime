## 3. 五类归类

### 3.1 底层已经在 V2

做事主路径、任务材料、页内成果与修改/导出、模型连接、重启恢复、主体 `captureInput` / 资料导入、协作占位。

### 3.2 仅 legacy 有产品实现

完整聊天工作台、帮助体系、「采用结果」与采用后学习、任务归档/搜索、七模块校对台、能力页、身份协作管理 UI。

### 3.3 V2 已有但体验退化

成果类型手动选择；缺采用闭环；数字之我可感知成长偏弱；无独立对话（本轮已最小补回）。

### 3.4 已被明确否决，不应恢复

「创作」一级入口；用户面必经计划确认；视频/音频成品宣称；公网协作/支付结算；默认暴露 MCP/协议黑话；主体完成度门禁；Fake 冒充产品路径；R3 迁移作为下一步。

### 3.5 应重新设计但不能遗忘

对话↔做事分流；采用+学习；使用即构建；帮助与状态标签；能力跟随；身份/授权最小语义。

## 6. 对话持久化选择

- **审计结果**：V2 无 Conversation/Thread/Message 领域对象；`sourceKind: conversation` 只是捕获来源。
- **本轮方案**：壳层辅助 transcript → `SubjectPackage/ui/conversation.ndjson`（role/text/at），**不进** `growth/`，不参与派生。
- **主体写入**：仍仅经 `subject.captureInput`。
- **停止条件检查**：未新建第二主体事实源；未重写 Work Runtime；未复制 legacy renderer；聊天历史 ≠ GrowthEvent。
