# Digital Me V2 引导验证脚本（2–5 人）

任务：`DIGITALME-V2-GUIDED-VALIDATION-READINESS-01`  
目标：在引导下完成主路径体验；**不要求**用户理解内部架构。  
产品状态：**引导验证** — **不宣称** MVP ready / closed alpha / production ready。

## 分发说明（给引导员）

1. 提供 Windows x64 可运行目录（`win-unpacked` 或解压后的 ZIP），含 `DigitalMeV2.exe`。
2. 在**新目录 / 新用户账号**启动；不要指向开发仓库、不要要求安装 Node、不要使用 Owner 本机绝对路径或开发凭证文件。
3. 用户自行在应用内粘贴模型密钥；密钥保存在本机应用数据目录。
4. 可选实验协作：需事先在本机准备**第二个** Digital Me 数据包目录（由引导员用同一应用另建，或导出副本），验证时在「协作 → 新建协作」中选择该文件夹。

## 用户流程（约 30–45 分钟）

| 步骤 | 操作 | 期望 |
|------|------|------|
| 1 | 首次启动 → 简短介绍 → **连接模型** → 保存并验证 → **开始使用** | 未连接前不会假装主功能可用；可「先跳过」但须看到提示：*可以先浏览，但对话和做事需要连接模型。* |
| 2 | 对话页发一句短话 | 有正常回复 |
| 3 | 数字之我页添加一份资料（文件或文件夹） | 列表可见 |
| 4 | 做事：完成一次写作任务 | 产出可阅读文稿 |
| 5 | 按说明修改，再**采用** | 状态变为已采用/已确认类用户文案 |
| 6 | 再做一个相关任务 | 观察是否减少重复说明（主观） |
| 7 | 退出应用并重启 | 资料、对话、任务仍在 |
| 8 | （可选）代码分析类任务 | 有结果或诚实失败提示，不虚报成功 |
| 9 | （可选）实验协作：选本机另一数字之我，发出并执行 | 导航有「实验」标记；无跨设备/公网宣称；中断后不应永久「正在处理」 |

## 引导员注意

- 不要讲解 Job、Record、Transport、Package 路径等内部概念。
- 专业能力（研究分析）在**设置**中配置；无验证通过前不得说「已连接」。
- 协作是实验能力，仅本机另一数字之我。
- 结果检查仅在真实检查通过时显示「已通过」。
