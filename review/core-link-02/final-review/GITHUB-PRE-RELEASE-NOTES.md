## 下载与启动

- 常规试用：下载 setup.exe 并安装。会使用正式应用数据目录；本版无需开发环境。
- 希望保留原观察版：下载ZIP，解压到新文件夹，用PowerShell显式指定独立数据目录后启动：

```powershell
$env:DIGITALME_V2_USER_DATA = Join-Path $env:LOCALAPPDATA 'digitalme-v2-core-link-trial-54adc4a'
$env:DIGITALME_V2_SEARCH_ENABLED = '0'
$env:DIGITALME_V2_ALLOW_DEV_CREDENTIAL = '0'
& '.\兔机米.exe'
```

请在解压目录执行；首次建立独立主体，普通托管能力使用产品入口，测试历史主体与凭据均不随包分发。要继续保留8d888b09观察版，请使用上述ZIP隔离启动，不用安装包覆盖它。

附件仅安装包、ZIP及SHA256SUMS.txt。未上传用户数据、凭据、令牌或私有测试主体。
