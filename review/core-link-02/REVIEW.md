已覆盖常用目录 feed 来源与外部搜索域名身份不同的情况。对缺少域名证据的旧自定义来源、共享平台作者，仍只能可靠按现有来源 ID 屏蔽；外部结果不提供该作者 ID 时，不能声称已经完成作者级跨入口识别，也不能误封整个平台。
