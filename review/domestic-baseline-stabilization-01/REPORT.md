## 2. 本轮修了什么

1. **首屏。** `mode=open` 且本地为空时，当场摄入目录 RSS / 开放媒体再返回。排序失败仍先展示已取到的目录卡。后续更新不清空列表。  
2. **国内默认新闻不再走 Google News。** `fetchNewsHeadlines` 只打目录 RSS，可选托管搜索作补充；Google News host 一律排除。有日期的目录条目优先于无日期搜索命中。  
3. **陈旧源退出默认目录。** 人民网时政 RSS 最新条目停在 2025-06-05，已移出 `OPEN_SOURCE_CATALOG`。21 天门槛继续挡默认近期供给。  
4. **来源边界跟重定向。** `classifyResolvedDefaultSource` 跟随最终 URL 再判断。  
5. **材料关联。** 导入绑定当前会话；第二场对话不自动带上。授权文件夹只给写，不给 `list_directory` / 擅自读其它文稿。指定一份时按该份交付。  
6. **媒体。** 不造播放器。木星视频来自 Commons 原文件，HEAD `200 video/webm`，188MB。

## 6. 网络验证范围与可执行复验

本机外网 200：IT之家、Solidot、Commons、iTunes、Archive、Google News、BBC（后两项仅对照）。  
人民网 RSS 200 但陈旧，已退出默认。

**缺口：** 没有国内普通网络探针。Commons / iTunes / Archive / 部分外媒在国内是否可达，本轮不能回答。

国内机器复验（同一组任务，隔离 HOME + 纯托管）：

1. 冷启动打开发现：首屏必须有卡，不能靠 more。  
2. `fetchNewsHeadlines('今日新闻')` 请求 URL 不得含 `news.google.com`；条目要有标题、日期、可打开原文。  
3. 打开一条 Commons / 原站媒体：HEAD 或短 Range，确认 `video/*` / `audio/*` 或原站播放页，而不是介绍文。  
4. 导入两份材料：第二场对话不带第一场路径；指定一份时交付只来自该份。  
5. 把结果标成「国内普通网络」，不得复用本机外网 JSON。
