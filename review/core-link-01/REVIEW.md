**当前 Talk 文档：** 已区分出回读工具接线缺口，并在本轮 B3 范围内补齐；最终真实写入与独立回读通过。模型对历史工具的自然语言回顾出现不准确，执行记录和文件事实优先，不能靠回复自证。

**取消 / 迟写：** [实际文件与调度时间线](evidence/cancel-late-write.json)。采用 scripted 模型输出，控制 `fs.stat` 等待边界，文件系统是真实的：

- 调用前取消：模型调用 0 次，文件未创建。
- 写入 preflight 的 await 边界取消：记录 cancel 后仍创建文件，记录 mutation=true，随后才返回 TalkCancelled。

根因位于当前 `runWriteFile` 的异步 preflight 与实际 mkdir/write 之间缺少取消复查；export 写入边界也需专项核查。**本轮仅提交诊断，没有修复取消 / 迟写。** 建议独立修复范围：在实际副作用提交前检查取消、保留已经发生的真实效果、不宣称取消能回滚已提交写入；覆盖文件新建、覆盖、Office 导出，以及取消后线程落盘。不得迁回旧 Job 或新建总控状态机。
