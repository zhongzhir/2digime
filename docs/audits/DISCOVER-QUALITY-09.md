## 1. 家庭共看（源码 harness，非 08 包）

隔离 `owner-copy`，`quality-09-family` / `quality-09-family-unused`。整点前额度空跑作废。

原句「周末和小学孩子看一部自然纪录片，不想开会员」：20.0s 出现央视网 / B 站等官方页；片单「免费全集」未抄成已核实。Bangumi 只作发现依据。

新表达「想找一部周末能和家人一起看的历史人文纪录片，最好不用开会员」：18.5s 出现《中华文明》《河西走廊》《中国通史》等官方页。

官方入口只证明能去原站打开。会员/免费当时有的卡是 `unconfirmed`，有的是空白 `none`。本轮收尾后：用户提了条件而页面没证实，每张节目卡都标未核实，并写明入口不等于条件已满足。

## 2. 屏蔽：对象是来源

界面「不再看这个来源」写入 `block` + `targetType=source` + `publisherSubjectId`。不是单条，也不是主题。

当时换一批后目标条还在，是过滤不统一：缓存回放、合并和连续加载没有都按来源排除。

本轮：`resolveCards`、默认流合并、刷新、重置、连续加载都走同一套来源过滤。专项：屏蔽后 reset / refresh / more 都不再出现该来源。

## 3. 连续加载

QUALITY-08 界面仍是 12 张，当时没分清是候选耗尽还是分页故障。

原因有两处：

1. 分页：第一屏只记下当前 12 个 id，剩余候选没有稳定进入 `rankedIds`，连续加载拿不到下一页。
2. 耗尽：没有下一页时应说明「暂时没有更多新内容」，不能假装还在加载。

本轮剩余候选进入 `rankedIds`；屏蔽来源从待加载列表去掉；没有新卡片时给出耗尽说明。专项覆盖「有剩余则追加 / 无剩余则说明」。

## 4. 条件标注

用户说了「不想开会员」而页面没证实：`conditions=none` 视为 `unconfirmed`，卡片写未核实，并写「官方入口只说明能去原站打开，不表示已经满足这次提出的条件」。

漫剧片段：`entrancePurpose` 为「部分匹配：去原站打开片段入口，不是完整节目」。

## 5. 本轮代码

- 候选 `channel`：观看 / 发现 / 补充。模型看页面，不看域名表。
- 官方 HTML 作品页无 RSS/直链仍是原站入口。
- 片单「免费、全集、无广告、公共领域」不抄成 `met`。
- 核实作品页保留用户这次的条件。
- 屏蔽来源在缓存、合并、刷新、连续加载统一过滤。
- 连续加载记下剩余候选；耗尽则说明。
