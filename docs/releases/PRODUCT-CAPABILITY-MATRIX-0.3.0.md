# 兔机米 0.3.0 产品能力说明

**日期：** 2026-11-28  
**适用版本：** 本地 Slice 5 候选，尚未签名、公开发布或生产部署

本说明只列入已经通过当前开发门的能力。`Beta`、`有限预览`和`伙伴沙箱`均表示能力边界，不代表相应能力族已经达到市场领先产品的 95%。

| 能力 | 状态 | 当前可以做什么 | 仍不属于已通过范围 |
|---|---|---|---|
| 与兔机米 / 数字之我 | 可用 | 在同一对话表达目标；查看、纠正和撤销系统对本人的认识；查看身份、授权、协作、自动化和机构连接投影 | 真实实名、KYC、金融账户和生产机构认证 |
| 发现 | Beta | 浏览相关内容；连续翻页；打开当前有效原文；反馈影响后续选择 | 稳定的短剧/视频直接观看入口；登录态平台内容；完整内容市场覆盖 |
| Word、PPT、PDF | Beta | 在对话中创建并打开三种文档；固定任务结构、回读和逐页渲染；对既有 DOCX 做少量精确文字修改并另存 | 复杂模板保真；公式、批注和复杂图表编辑；既有 PPTX/PDF 原格式复杂修改 |
| 授权本地文件 | 可用 | 在用户明确授权的文件或文件夹内搜索、读取、创建、编辑、复制、移动、重命名；删除和不可逆覆盖在执行时确认 | 越过授权根；读取系统或浏览器凭据；未确认删除；通用文件管理器替代品 |
| Coding | Beta | 用户只在兔机米对话中描述目标；系统可自动获得并调用成熟编程能力，交付实际文件和验证结果 | 所有语言、仓库和开发环境的市场 95%；生产发布和高风险外部操作 |
| 第三方系统 | 有限预览 | 通过统一连接合同调用已配置的只读工具或机构服务，并保留真实执行事实 | 任意第三方系统即插即用；通用网页代操作；生产账号写操作 |
| 协作 | Beta | 两个数字主体通过既有 Relay/E2EE 和标准对象完成请求、接受/拒绝、成果返回、结束与撤销 | 公网大规模主体发现；独立外部伙伴验收；交易和支付 |
| 自动化 | 有限预览 | 用自然语言创建人在环自动化；低风险本机成果链可在现有授权内自动运行，并可暂停、恢复和撤销 | 默认联网、外发、付费、删除、权限变更或无人值守高风险执行 |
| 机构合作 | 伙伴沙箱 | 用合成数据创建机构、测试用户、权益和服务；演示电信权益与银行服务协作；查看最小审计和隐私边界 | 真实银行/电信生产接入；真实 KYC；FAPI 2.0 生产互操作；数字人民币或其他金融工具 |

## 安全与发布边界

- 当前 Windows 候选为每用户安装，不要求管理员权限；卸载不删除 `%APPDATA%\digitalme-v2` 中的个人数据。
- 当前候选没有 Authenticode 代码签名，Windows 可能显示未知发布者。签名需要单独的证书与发布授权。
- 当前候选不是公开 Release；没有 push、公开发布、生产部署或真实机构试点。
- 任何付费、对外发送或发布、删除、不可逆修改、凭证授权和权限扩大仍需用户明确同意。
