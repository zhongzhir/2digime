# 2digime 0.3.0 Development Baseline

**日期：** 2026-11-22  
**版本：** `0.3.0`  
**标识：** `DEVELOPMENT_BASELINE / NOT_A_PUBLIC_RELEASE / NOT_PRODUCTION_DEPLOYED`

## 本版本包含

- Owner 限定接受的 Discover 第一阶段：关联度、无关内容控制、连续供给、来源组合与同一主模型整体选择；
- `DISCOVER-WATCH-ENTRY-01` 已实现的通用页面读取、具体对象与推荐依据分离、观看入口和访问限制事实投影；
- 既有 Digital Self、Talk、做事 runtime、Relay、Subject 通信与机构分发地基；
- 为下一阶段机构级主体身份、认证、安全、A2A 与做事协作保留的唯一计划入口。

## 本版本不代表

- 不代表推荐卡可以稳定直接观看或试看；公开网络覆盖仍受内容平台生态限制；
- 不代表外部搜索供应商、平台登录态、付费能力或生产 Relay 已新增；
- 不代表机构级 OIDC/FAPI、VC/OpenID4VC、A2A 互操作或两 Owner 真实试验已经完成；
- 不代表公开发布、生产部署、迁移、安全认证或 Owner 对完整产品的最终验收。

## 下一版本方向

只按 `docs/refoundation/03-CURRENT-PLAN.md` 执行 `INSTITUTIONAL-SUBJECT-COLLABORATION-01`。第一批是身份现状/威胁审计与签名 Agent Card；未过门前不扩建协作 UI、不增加新 runtime、不接真实机构数据。
