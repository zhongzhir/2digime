# 使用反馈（4）

状态只记录已经落地的行为和仍然没做的需求。本轮没有把未实施项标成完成。

| 项 | 状态 | 说明 |
|---|---|---|
| 发现里尽快看到已取到的内容 | 已测到有用内容，确认列表仍慢 | 冷启动约 2.6 秒，再次打开约 0.5 秒。新闻摘要约 1 秒，确认后的列表约 55–57 秒 |
| 当天新闻不把综述当完成 | 部分达到 | 气象查询给出了带日期的预报。台风查询的确认列表里仍有一篇季节综述 |
| 验证页不当成正文 | 已接到访问状态 | 标题本身是访问验证的页面不再当正文。窗口里仍见过未套上该状态的旧结果 |
| 对话里使用已有网页搜索 | 已接上 | 分子式直接回答。台风问题实际搜索并给了链接，追问沿用了上一条来源 |
| 音频、视频连续播放 | 已测播放、暂停、跳转 | 音频播到约 1.3 秒后暂停并跳到约 5.3 秒。视频播到约 0.3 秒后暂停并跳到约 4.3 秒。错误码为 0 |
| 对话删除 | 未实施 | 仓库里没有删除会话的入口 |
| 对话改名 | 未实施 | 仓库里没有会话改名 |
| 项目归集 | 未实施 | 没有把多次委托收成一个项目的产品路径 |
