# 兔机米 Public Alpha — Windows 试用说明

[English README](../../README.md) · [中文 README](../../README.zh-CN.md)

给**普通试用者**。当前公开目标：**Windows x64**。macOS 尚未完成 Public Alpha 验证；Linux 不宣称支持。

这是早期 Public Alpha，不是生产就绪产品。

---

## 1. 下载并启动

发布后，从 [GitHub Releases](https://github.com/zhongzhir/2digime/releases) 下载最新的 Windows x64 Public Alpha（ZIP）。本说明不绑定某个尚未发布的文件名。

1. 解压到任意文件夹。不需要安装程序。  
2. 双击 `兔机米.exe`。

**不需要** Node、npm、Git、Python、Docker，也不需要事先安装任何编程助手。

Public Alpha **尚未完成代码签名**，因此 Windows 可能显示未知发布者提示。请只在文件来自本项目官方 Releases、且你信任该来源时继续。不要为此关闭系统安全功能。

用完后删除解压出的文件夹即可。密钥只留在你这台电脑上，不会打进下载包。

---

## 2. 连接 AI

聊天和做事都要先连上一个 AI。密钥只保存在本机。

1. 打开 **设置**（首次也可能先看到「连接 AI」页）。  
2. 在 **AI 连接** 里选择你使用的服务（试用时常用 **DeepSeek**，它不是唯一选择）。  
3. 把密钥粘贴进输入框。  
4. 点 **保存**（欢迎页是 **保存并验证**）。需要时再点 **测试连接**。  
5. 回到 **与兔机米**。

还没连上时，对话不会假装已经完成。

日常不必打开设置里折叠的「高级」项。

---

## 3. 第一次试用（只做这三件）

### A. 先聊天

在「与兔机米」里直接说，例如：

> 我最近正在做一个 AI 产品，你先通过交流了解一下我。

### B. 让它做一件真实的小事

把一个文件或文件夹加入**这次对话**（「这次一起看」），然后直接告诉它你想完成什么。例如改一段说明、整理一份草稿、给一个小程序加一点行为并检查能不能跑。

你不需要知道背后用了哪种专业能力。做成的结果会留在同一段对话里，主按钮是 **打开**。

### C. 看「数字之我」

再聊几轮，打开 **数字之我**：看它现在怎样理解你、来源是什么，然后**纠正一条**。这些认识属于你。

---

## 4. 关于「连接世界」（实验中的核心能力）

2digime 正在验证一种新的数字主体网络：信息和服务可以由中间网络提供，但最终什么值得你看到，由属于你的数字之我自行判断。

当前试用**没有** Feed 页面，也没有关注/订阅。请不要在软件里找「网络」或「协作中心」。那不是这个 Alpha 的入口。
