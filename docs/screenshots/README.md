# Screenshots

This directory is a **placeholder** for screenshots. We deliberately do **not** commit fabricated or staged screenshots.

To add a genuine screenshot:

1. Run the Windows Preview (or `npm run dev`) and capture real UI states of the four surfaces: 对话 (Talk), 做事 (Do), 数字之我 (Digital You), 协作 (Collaborate, experimental).
2. Save as `.png` here and reference it from `../../README.md` and `../windows-preview/README.md`.
3. Make sure no personal data, API keys, or internal paths appear in the images.

Until real captures are added, the project relies on the written demo script in `../competition/02-generic-materials.md`.
