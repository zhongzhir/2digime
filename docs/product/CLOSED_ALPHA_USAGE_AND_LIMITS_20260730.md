# Digital Me 封闭内测使用说明与已知限制

- **版本**：0.1.0 Closed Alpha
- **构建形态**：`portable_closed_alpha_build`（目录型，未签名）
- **状态标签**：`unsigned_closed_alpha_build` — **不是**公开发行版

## 如何获得并启动

1. 获取构建产物目录 `win-unpacked`（或同内容的 zip）。
2. 解压到本机任意可写位置（勿放在需管理员权限的系统目录）。
3. 双击 `Digital Me.exe` 启动。
4. **不需要**安装 Node.js、Git，也**不需要**运行 PowerShell 或 `npm start`。

## 首次使用建议路径

```text
创建或导入 Digital Me
→ 在设置中连接模型
→ 新建任务并填写要求
→ 添加任务材料（文件或文件夹）
→ 开始做
→ 在页内查看成果
→ 提出修改并生成新版本
→ 采用结果 / 打开本地文件
→ 完全退出后重启，确认任务仍在
→ 创建同类新任务，观察是否减少重复说明
```

## Windows 安全提示（SmartScreen）

本构建**未购买代码签名证书**。首次打开时，Windows 可能显示「Windows 已保护你的电脑」或类似提示。

- 这是未签名封闭内测包的预期现象，不是应用被篡改的证明。
- 仅在你确认文件来自项目 Owner / 指定分发渠道后再继续运行。
- 不要把本包当作面向公众商店的正式安装版传播。

## 数据与卸载边界

- 应用配置位于系统 userData；Digital Me Package 位于「文档」或你指定的目录，与安装/解压目录分离。
- 删除应用目录或卸载**不应**自动删除你的 Package 内容；请自行备份重要 Package。
- 不要把 API Key 写进分享出去的配置或截图。

## 已知限制（封闭内测）

1. 未签名；SmartScreen 可能拦截。
2. 当前优先交付目录型 portable；单文件安装器可能尚未提供。
3. 学习以规则归纳为主；复杂偏好仍可能需要少量再次说明。
4. 视频/音频成品、外部协作网络、云同步、自动升级不在本 Alpha 范围。
5. 「身份与协作」「能力」入口收在「我的 Digital Me」内部，默认不占据主导航。
