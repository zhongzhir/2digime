# Digital Me — 一页项目简介

## 一句话

**Digital Me** 是一个**由你掌控**的个人数字主体：它代表你、为你做事、并在授权下与他人协作——架构是 AI-native 的控制层，而不是一个套壳聊天机器人。

## 它是什么

Digital Me 是一套桌面应用，帮助你构建一个"数字之我"：

- **代表我**：一份唯一权威的、由你确认过的本人事实与边界记录；回复遵守它，事实不足时不编造。
- **做事**：把意图变成有范围、有规划、有独立验收的真实动作——包括在你授权的项目文件夹里改代码——做完由你决定是否采用。
- **协作（实验）**：在授权与加密下，与另一台电脑上的 Digital Me 收发消息、发现机会、提出协作。

## 为什么不是普通 AI Agent

普通 AI Agent 是面向任意提问者的通用、无状态模型。Digital Me 的不同在于：

1. **身份由你掌控**——外部模型/Agent/工具都不能未经确认写入"你是谁"。
2. **模型是能力，不是主体**——Digital Me 选择、授权、调用、验收真实能力，不重复造 Agent 内核。
3. **诚实停机**——能力未连接时不假装成功。
4. **成长闭环**——完成并采用的工作回流到你的主体，让系统越来越懂你。

## 当前真实能力

- 对话（含已确认本人事实，不自由推断）
- 做事：在授权目录内，用真实外部 Coding Agent 或已连接模型改代码，独立运行测试验收，成果可查看/修改/采用
- 数字之我：查看与渐进构建已确认内容
- 协作（实验）：跨电脑配对、加密信件、机会发现、提出协作

## 架构为什么 AI-native

见 [docs/architecture](../../architecture/)。核心是单一领域模型 + 一条执行路径 + 可插拔 Capability Adapter + UI 只做派生投影 + fail-closed 安全。领域层零 Electron 依赖，可纯 Node 测试。

## 真实阶段

**实验性 Preview**，不是 MVP、不是生产就绪、不宣称市场 95 分位。Owner 已在集成基线上真机验收主路径（对话/做事/采用/成长）。协作仍为实验，不能当完整远程交活。仓库提前公开，供评审、早期试用与诚实评估。
