## 200 字简介

Digital Me 是一个**由用户掌控的个人数字主体**。它不是普通 AI 聊天助手，而是一个 AI-native 的控制层：它代表你、为你做事、并在授权下与他人协作。你构建一份唯一权威、经你确认的本人事实与边界；Digital Me 在此基础上，把意图变成有范围、有规划、有独立验收的真实动作——包括在你授权的项目文件夹里改代码——成果由你决定是否采用。系统选择、授权、调用并验收真实的 Coding Agent 与只读工具，不重复制造 Agent 内核；能力未连接时诚实停机，绝不假装成功。当前为实验性 Preview：对话、做事、数字之我可用，跨电脑协作为实验能力。

## 500 字项目说明

Digital Me（项目代号 2digime）是一套桌面应用，帮你构建"数字之我"。它解决一个根本问题：当 AI 越来越强，如何让 AI **代表你**做事，而不是替你做主。

架构是 AI-native 的，而不是给聊天应用包一层模型。核心分层：

- **Subject Core（主体）**：唯一权威的"你是谁"——你确认过的事实、偏好、边界与成长事件。外部模型、Agent、工具都不能未经你的确认写入它。
- **Work Runtime（做事）**：一条正式执行路径：任务 → 上下文快照 → 选择能力 → 执行 Job → 产物 → 反馈。范围先校验后写入，结果独立验收。
- **Capability（能力层）**：模型、Coding Agent、只读工具经统一 Adapter 接入。Digital Me 选择、授权、调用、验收真实能力，不重造 Agent 内核。
- **Collaboration（协作，实验）**：主体与主体之间基于授权与加密的协作。

当前真实能力：对话（遵守已确认本人事实，不编造）；做事（在授权目录内，用真实外部 Coding Agent 或已连接模型改代码，运行测试独立验收，成果可查看/修改/采用）；数字之我（查看与渐进构建）；协作（实验：跨电脑配对、加密信件、机会发现、提出协作）。

当前为**实验性 Preview**：不是 MVP、不是生产就绪、不宣称市场 95 分位。Owner 已在集成基线上真机验收主路径。协作仍不能当作完整远程交活。我们提前公开，供评审、早期试用与诚实评估——AI 越强，越需要一个由人掌控的"数字之我"。

## 核心创新（技术创新，≤5 点）

1. **Owner-controlled 数字主体**：以"经你确认的本人事实"为唯一权威，外部能力不得未经确认改写主体；回复遵守它且事实不足不编造。
2. **AI-native 控制层，而非套壳**：单一领域模型 + 一条执行路径 + 可插拔 Capability Adapter；UI 只做派生投影，不持独立事实。
3. **真实能力编排 + 独立验收**：Digital Me 不重复造 Agent 内核，而是选择/授权/调用真实 Coding Agent 与只读工具，并对结果独立运行测试验收、由你决定是否采用。
4. **范围安全与诚实停机**：写入前先校验全部路径（禁止越权/盘符逃逸）；能力未连接时诚实停止，绝不假装成功。
5. **成长闭环**：完成并采用的工作以事件回流到主体，让系统在"代表你 × 做事 × 协作"上持续演进。

## 用户价值（≤5 点）

1. 你的数字分身**代表你**：一份由你掌控、经你确认的个人档案，跨场景一致。
2. **为你做事**：用真实工具在你授权的范围内完成真实任务（含改代码），有独立验收与成果采用，而不是空谈。
3. **诚实可信**：能力未连接就直说，不假装完成；你的密钥只保存在本机。
4. **越用越懂你**：完成并采用的工作回流，系统持续成长，而不是每次从零开始。
5. **（实验）与你协作**：在授权与加密下连接另一台电脑上的数字之我，探索跨主体协作。

## 演示脚本（3–5 分钟）

1. **[0:00–0:40] 打开与诚实停机**：启动 Preview，未连模型时打开「对话」与「做事」，演示系统诚实说明需先连接模型、不假装成功。
2. **[0:40–1:40] 连接模型 + 数字之我**：到「设置」连接你的模型；打开「数字之我」查看已确认内容；说明"代表我"。
3. **[1:40–3:00] 做事闭环（核心）**：添加一个授权项目文件夹，描述一个小任务（如"去除多余空格"或"修一个显示名"），确认范围 → 规划 → 用真实 Coding Agent 或已连接模型完成 → 独立运行测试 → 查看/修改/采用成果。
4. **[3:00–3:40] 成长回流**：采用后回到「对话」，提到刚完成的事，演示"做事经历"已回流。
5. **[3:40–4:30] 协作（实验）**：打开「协作」，展示能做什么（连接另一台电脑的数字之我、加密信件、机会发现、提出协作）与不能做什么（不能当作完整远程交活）。
6. **[4:30–5:00] 真实阶段声明**：明确这是实验性 Preview，非 MVP、非生产就绪；突出"Owner-controlled"与 AI-native 架构。
