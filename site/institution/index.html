Institution distribution

把 AI 能力，变成你的用户产品。

机构可以用自己的品牌提供基于 2digime Core 的 AI 产品，向不同用户分发权益、管理额度与用量，并在合作中对接现有系统。用户的 Digital Self 仍然属于用户。

Brand Kit

机构品牌在前，开放 Core 在后。

同一套 2digime Core 可以通过 Brand Kit 生成不同产品身份，无需 fork 一套机构专用 Core。名称、图标、关键文案与主题 token 均由配置驱动。

右侧 Demo Telecom 仅为架构验证使用的虚拟示例，不代表任何真实电信机构合作。

合作实施

主体与数据边界

机构拥有服务关系，不拥有用户数字主体。

运营所需的数据与用户私密内容需要被清晰分开。

机构可以管理

  • 机构用户身份映射
  • 套餐、权益与有效期
  • AI provider / model / capability
  • 额度、必要用量与成本统计
  • 品牌配置与机构系统接口

默认不进入机构后台

  • 用户 Digital Self 内容
  • 私人 Talk 的 prompt / response 正文
  • 私人文件与长期记忆
  • 用户自己的主体资产
  • provider master key

合作路径

从真实用户产品出发

定义产品与用户权益

明确机构希望提供给谁、解决什么问题，以及 AI 权益的范围和可持续成本。

用 Brand Kit 建立产品身份

配置品牌、支持入口与必要主题，不复制或分叉 2digime Core。

对接机构现有系统

在合作中实施 SSO、用户开通、权益发放、usage callback、billing 或 CRM sync。

按真实场景验收

验证用户能直接使用 AI、额度彼此隔离、用量可归集，同时用户主体数据不越界。

讨论你的机构 AI 产品。

当前不提供误导性的机构正式产品下载。请通过公开 GitHub Repository 或 Issues 了解架构、提出合作需求。
