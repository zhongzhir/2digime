Personal Agent 时代：人真正掌握数字世界入口

大厂推出 Personal Agent，不是突然把控制权交还给用户，而是在争夺下一代互联网最重要的入口。谁掌握 Agent，谁就可能掌握需求从哪里进入、服务由谁提供、交易流向哪里。真正的变化必须从入口的归属开始：让人真正掌握数字世界入口。

兔机米编辑部 · 人工撰写

大厂推出 Personal Agent，不是因为它们突然决定把数字世界的控制权交还给用户。恰恰相反，它们正在争夺下一代互联网最重要的入口。

过去，用户通过搜索框、社交平台和超级 App 进入数字世界。现在，用户开始直接对 Agent 说出目标，让它替自己搜索、选择、沟通、购买、执行。谁掌握了这个 Agent，谁就可能掌握用户的需求从哪里进入、服务由谁提供、交易流向哪里。

所以，大厂做 Personal Agent 的真实战略，不只是「让 AI 替用户办事」，而是把流量入口从 App 和搜索框，进一步推进到用户的意图、记忆和行动之中。它们在讲一个为用户服务的故事，争夺的却是更深一层的控制权。

这些 Agent 正在争夺人进入数字世界的入口

市场上的 Personal Agent 已经呈现出不同形态。ChatGPT Agent 使用浏览器和连接器处理多步骤任务；Manus 面向研究和复杂工作；Meta Muse 连接个人应用与服务，尝试处理购物、邮件和日程；OpenClaw 以开源方式让用户自行部署个人助理；豆包手机助手则尝试直接进入手机系统，跨应用替用户操作。它们看起来路线不同，争夺的却是同一件事：成为用户发出需求后，最先接收任务、最有权安排服务的那个入口。

用户已经看到了 Agent 的便利：减少重复操作，快速整理信息，处理复杂任务。但真实使用也暴露出另一面：Agent 会犯错，会在关键步骤卡住；要让它完成任务，用户往往需要交出账号权限、个人信息和行动空间。用户得到便利的同时，也可能把更多数字生活交给提供 Agent 的平台。大量用户对 Muse、Dots 等产品的实测显示，它们在研究和准备任务上有亮点，实际购买等连续操作却并不总能完美执行。

这不是技术发展中的小插曲。它说明谁控制 Agent，谁就不只是在提供一个工具，而是在争夺用户下一步做什么的决定权。

为用户服务的叙事，掩盖了平台的深层布局

大厂说，Agent 是为了让用户更方便。但方便并不会自动带来自由。如果 Agent 优先调用自家服务，优先呈现自家商品，优先把用户留在自家账号、支付和应用体系里，那么它只是把平台的商业目标藏进了一次自然语言对话。

过去，平台靠推荐算法分配流量；未来，平台可以让 Agent 替用户做选择。过去，用户至少还能看见不同 App；未来，用户可能只看见 Agent 给出的一个答案、一项服务、一个购买选项。入口从屏幕上的图标变成了看不见的调度过程，平台的控制反而更深了。

不必揣测大厂的想法，商业逻辑已经足够清楚：没有任何服务供应商愿意长期替竞争对手做嫁衣。它们都想让自己的 Agent 留住用户、调用自家生态、获得更多交易。用户想让 Agent 从全网挑选最好的服务；平台想让 Agent 把用户带回自己的地盘。这个矛盾将在很长时间持续。

豆包手机把遮羞布揭开了

豆包手机助手尝试替用户跨应用操作，随后遭遇应用限制、安全提示和部分功能调整。微信、淘宝、支付及银行等场景中的摩擦，把一个事实摆到了台面上：当 Agent 有能力绕过 App 的界面，直接替用户完成任务，平台就必须面对流量、数据和交易控制权被削弱的现实。关于第三方应用能否设置 GUI 自动化权限的讨论，也说明这不是普通的产品兼容问题，而是新入口与旧平台之间的权力冲突。

安全问题是真实的，需要解决。但安全有时也会成为借口。平台一面宣称自己服务用户，一面又要求用户只能通过平台认可的入口、按照平台允许的方式使用服务，这种「开放」最终服务的仍是平台自己。

个人 Agent 打破垄断，没有不可逾越的技术门槛

人们常常误认为只有大厂才能提供真正有用的 AI。事实并非如此。

开源软件、强大模型、Agent 框架、Skill 和各类工具接口，已经让个人和独立团队能够把现成能力组织起来。个人不必训练自己的大模型，不必复制大厂的全部服务，也不必先获得平台许可，就能拥有一个自己的 Agent。兔机米等原生 Personal Agent 的发展已经说明，个人部署、开放协作和工具组合不是遥远的设想。

有些平台会限制接口，有些应用会拦截自动化操作。这是平台设置的边界和利益防线，不是证明个人 Agent 在技术上做不到。只要 AI 能力可以被调用，工具可以被组合，个人 Agent 就能从平台生态中独立出来，代表个人连接数字世界。

兔机米选择的正是这条路。兔机米不需要独立训练一个比所有大厂都强的模型，也不需要建一座更大的封闭平台。它要做的是把个人的数字之我与 AI 能力连接起来：个人掌握自己的记忆、判断、表达和授权规则，再由 Agent 根据任务，在全网选择合适的模型、工具和服务，而不依赖于任一家平台的产品或服务。

让人不再是平台精心投喂的肉鸡

在旧互联网里，平台采集人的行为，理解人的偏好，再把内容和商品推到人面前。用户看似在自由选择，实际常常是在平台安排好的货架里移动；人的注意力变成流量，人的行为变成数据，人的选择又被拿去训练下一轮推荐。

Personal Agent 本来可以改变这种关系：由用户提出目标，由属于自己的 Agent 去寻找信息、比较服务、调用能力。人不再只能等待平台投喂，也不必把全部数字生活交给一个商业生态。

但如果 Agent 属于大厂，平台只不过从「给你推什么」升级到「替你选什么」。那时的人仍是平台精心投喂的对象，甚至是更高效地贡献数据和交易的肉鸡。真正的变化必须从入口的归属开始：Agent 要能代表个人，而不是把个人更彻底地交给平台经营。

数字之我也不是一个只会模仿真人口吻的数字分身。它意味着个人可以把长期积累的经验、判断和能力带进数字世界，让它们在 AI 的帮助下持续发展。人不是被算法照料的对象，而是自己的数字主体的主人。

这场变化不会一夜发生，但已经开始

大厂有资金、用户和成熟生态，当然会继续发挥自己的优势，争取更多的人只用自己提供的 Agent 工具。个人 Agent 的易用性、跨平台连接和安全授权也还需要发展。但这不代表用户只能接受大厂提供的入口，更不代表大厂的垄断已经成为不可改变的现实。

个人追求自由、主导自己生活的力量正在萌芽。最早行动的人会尝试开放工具、独立 Agent 和可迁移的个人资产；更多人会逐渐意识到，进入数字世界不必从选择一家大厂的 Agent 开始。大量低成本、甚至零成本的开源 Agent 产品，正在进入原先高高在上的个人 Agent 市场，为人们提供完全自主的选择。AI 能力越强，个人组织能力的成本越低，平台「只有我能替你办事」的幻觉就越难维持。

新的开源 Agent 产品不是为了把用户从一个平台搬进另一个平台，也不是为了建立新的流量垄断。独立 Personal Agent 团队如果最终仍然靠锁住用户、占有数据、控制服务来赚钱，那不过是换了一批人重复旧互联网的故事。这条道路在 AI 时代已经行不通了。

变革首先要发生。个人需要先拥有自己的数字入口，能够选择最适合自己的模型、Agent、工具和服务。新的商业模式可以在开放协作中逐步形成，但它不能再以牺牲用户的选择权为代价。
