AI 与人2026年10月6日

个人 AI 助理产业研究报告

2026 年个人 AI 正从聊天工具转向长期代理；竞争焦点是上下文、授权与代理权。新的 personal AI 机会在数字之我 + Agent Orchestration，而非再做一个万能助手。

兔机米编辑部 · 人工撰写

个人 AI 正在从“能回答问题的聊天工具”演变为“长期了解用户、能够持续执行任务的数字代理”。下一阶段的核心竞争，不只是“谁替用户把事情做得更好”，更是“谁掌握用户的长期上下文、授权关系和代理权”。

摘要 六个核心判断

  • 2026 年是个人 AI 从聊天机器人向长期代理系统加速转折的一年。Muse、Dots、Cue、Siri AI、 Gemini Personal Intelligence、Celia、miclaw 等产品开始把“理解个人、持续运行、调用工具、代为执行”组合成新的产品形态。
  • 个人 AI 真正争夺的不是一个聊天窗口，而是人与数字世界之间的“智能中介层”。谁能够持续理解用户、接收授权并完成行动，谁就可能重构搜索、软件、购物、本地生活和服务交易的入口。
  • 产业竞争已经分化为五条路线：大模型入口、操作系统与设备、独立个人 Agent、Agent 身份型产品，以及更长期的 Personal Intelligence / 数字之我。不同路线拥有完全不同的护城河。
  • 基础模型的重要性仍然很高，但长期看，个人上下文、执行环境、授权体系、账户与交易能力，以及用户迁移成本，将成为更持久的竞争壁垒。
  • 目前最明显的市场空白并不是“再做一个万能助手”，而是可迁移的个人上下文、细粒度授权、可审计的代理关系，以及独立于单一平台存在的用户数字主体。
  • 对 2digime 而言，战略机会不是复制 Muse、Cue 或 Dots 的通用执行能力，而是构建“数字之我 + Agent Orchestration”：让数字之我属于用户，并调用当下最强的模型、Agent、Skill 与 Tool 完成任务。

一 行业定义：个人 AI 助理已经不是传统“助手”

“AI Assistant”已经成为一个过于宽泛的概念。语音助手、聊天机器人、AI Agent、AI Companion、AI Browser 乃至 AI OS，都可能被放在“个人助理”这个标签下。如果不重新界定，很难理解今天的产业竞争究竟发生在哪里。

本报告将“个人 AI 助理”定义为：以特定个人为持续服务对象，能够积累个人上下文，并通过数字工具自主或半自主完成任务的长期 AI 系统。

它至少具备四个基本特征：

  • 认识这个人：不只理解当前提示词，还能逐渐掌握用户的历史、偏好、关系、文件、日程、工作和长期目标。
  • 能够行动：从“告诉你怎么做”升级为“搜索、分析、规划、调用工具并完成任务”。
  • 持续存在：任务不会随着一次对话结束，Agent 可以在后台持续运行，并在条件满足或出现风险时再次找用户确认。
  • 接受授权：一旦 AI 能够发邮件、下单、付款、修改账户，产品的核心问题就从“智能”延伸到“用户究竟授予了它什么权力”。因此，Personal AI 的最终形态并不是“更聪明的聊天机器人”，而是一套由个人上下文、智能推理、持续执行和委托授权共同组成的个人智能系统。

二 为什么是现在：三个条件同时成熟

1. 大模型第一次能处理开放式目标

过去的 Siri、Alexa 和 Google Assistant 主要依赖固定意图识别，擅长“播放音乐”“设闹钟”“查看天气”之类明确指令。大模型出现后，系统第一次能够理解模糊、复合、需要权衡的目标，例如“根据学校日期、预算和我们过去喜欢的酒店，规划一趟秋假旅行并给出推荐”。这类任务无法被预先写成一组固定 Intent。

2. Computer Use 打破了 API 边界

过去数字助手能做什么，很大程度取决于外部服务有没有开放 API。Browser Use 与 Computer Use让 Agent 可以直接操作网页、浏览器、桌面软件和文件系统。对普通消费者而言，这一步的意义非常大：许多现实任务并没有标准化接口，但人类原本就是通过界面完成它们。

3. Agent 工程从“单次调用”变成“长期运行系统”

一个真正的个人 Agent 往往要经历规划、搜索、工具调用、重试、验证和恢复，不能再把产品理解成“Prompt + 模型 API”。2026 年的一个明显变化，是头部产品开始公开强调 Agent Harness、Cloud Computer、任务调度、权限审批和独立安全代理。个人 AI 因此开始拥有类似操作系统的工程复杂度。

三 市场进入平台级竞争：资本与大厂同时加速

资本市场已经开始把 Personal Agent 视为消费者 AI 的重要独立赛道。Dealroom 对 49 家个人 Agent创业公司的追踪显示，相关融资从 2023 年的约 8700 万美元，增长到 2025 年的约 6.2 亿美元；2026 年截至 9 月已达到约 18 亿美元。即使剔除每年融资额最大的单一公司，融资规模仍然保持快速增长。与此同时，产品发布也高度集中。Dealroom 统计的 17 个大型科技企业 Personal Agent 中，有 9 个在 2026 年首次面向消费者推出相关能力。个人 AI 已经从创业公司的概念验证，进入大模型平台、手机厂商、云平台和消费互联网公司的正面竞争。需要谨慎看待各机构给出的市场规模。Gartner 所谓约 2220 亿美元的机会，覆盖的是更广义的“消费者 + 跨职能 Agentic AI”，不能直接等同于个人助理的纯市场规模。但无论采用哪一种口径，融资、产品发布频率和系统级入口的投入都在指向同一个结论：个人 AI 正在从功能模块上升为新的平台竞争层。

四 五条产品路线：看似都叫“个人助理”，实际上在争不同的

位置路线代表产品主要优势ChatGPT / Dots、大模型入口型Gemini、Claude、强模型、强用户入口Grok Siri操作系统与设备型个人上下文与能力容易锁定在单一模型平台系统权限、设备数据、跨平台性弱，受生态边默认入口界限制Instinct、Town、Lulia专注真实任务交付，产获客成本高，缺少系统等品迭代快级权限AI、Gemini/Android、 Celia、miclaw、Alexa+

独立 Personal Agent主要约束路线代表产品主要优势Agent 拥有邮箱、电Agent 身份型Cue by Manus话、钱包、电脑等独立行动身份Personal Intelligence / 数字之我行业仍处早期主要约束治理、安全与责任边界复杂长期个人模型、可迁移工程复杂，短期商业验上下文、用户主权证较难大模型入口型这类产品从“最强模型 + 最大 AI 入口”自然演进：聊天 → 记忆 → 工具调用 → Computer Use → Tasks → Persistent Agent。优势是用户已经习惯在这里提出复杂问题；弱点是用户的长期记忆、工具连接和工作流天然附着在平台上，切换模型的成本越来越高。

操作系统与设备型Apple、Google、华为、小米、Amazon 的优势并不只是模型，而是系统权限。一个真正的 Personal AI 最需要“持续数据 + 系统权限 + 设备入口”，这恰恰是手机、电脑、家庭设备和操作系统厂商天然拥有的资源。未来操作系统的核心交互可能从“打开哪个 App”逐步转为“我要完成什么”。

独立 Personal Agent这一赛道最直接的产品逻辑是：不要求用户学习 AI，而是像使用真人助理一样直接提出委托。创业公司更容易针对高频痛点快速迭代，但长期会遭遇两个结构性问题：一是缺少系统级权限，二是当大厂补齐通用执行能力后，单纯“替用户办事”的差异化会迅速收窄。

Agent 身份型Cue by Manus 值得特别关注。它不只是让 AI 使用用户已有账户，而是尝试让 Agent 自己拥有邮箱、电话号码、钱包和独立电脑。这个变化意味着 Agent 正在从“软件能力”向“可以参与数字活动的行动单元”演进。未来围绕 Agent 身份、账户、信用、钱包和责任归属，可能形成新的基础设施。

Personal Intelligence / 数字之我这是目前产品成熟度最低、但长期战略价值可能最高的一条路线。行业现在普遍把 Memory 理解成“保存历史、检索相关信息、放回上下文”，但真正理解一个人需要持续建模其身份、目标、关系、偏好、决策方式、承诺和边界。它不是一个静态 Persona，而应是能观察、学习、修正、更新、遗忘的Living User Model。

五 技术底座：个人 AI 正在形成新的八层技术栈

这八层中，基础模型仍然决定上限，但真正决定个人 AI 体验的部分越来越上移：个人上下文决定“懂不懂你”，Agent Harness 决定“会不会做事”，执行环境决定“能不能真正完成”，授权与身份决定“敢不敢把事情交给它”，交易能力则决定它是否会成为新的商业入口。

六 竞争壁垒：模型之外，真正稀缺的是“持续关系”

壁垒典型拥有者产业意义基础模型OpenAI、Google、Anthropic决定推理与生成能力上限，但长期可能趋向多模型与可替换用户入口ChatGPT、Meta、Google降低获客成本，决定用户是否愿意把任务首先交给它操作系统与设备Apple、Google、华为、小米拥有系统权限、传感器、本地数据与默认入口个人数据图谱Google、Apple、Meta长期积累的邮件、照片、关系、位置、行为很难复制执行环境Muse、Manus 等Cloud Computer、浏览器、后台运行与恢复能力直接决定任务完成率身份与交易Cue 等邮箱、电话、钱包、支付与账户让 Agent 进入真实经济活动信任与治理仍在形成授权、审计、撤销、解释与安全将直接决定用户是否愿意长期委托Personal Model / 数字之我尚无绝对领导者如果能够独立、可迁移地沉淀“这个人”，可能成为最强长期锁定与反锁定能力

七 商业模式：订阅只是起点，真正的大市场可能来自交易

今天个人 AI 最直观的商业模式仍然是订阅。市场已经出现从免费到每月 20 美元、100 美元乃至 200美元以上的不同层级。但如果 Personal Agent 真正成为互联网入口，订阅未必是最大的收入来源。

  • 订阅：用户直接为个人 AI 服务付费，类似 SaaS，但对象从组织软件变成“个人智能服务”。
  • 交易分成：Agent 帮助用户订酒店、买机票、购买商品、保险或金融服务后，可能从交易中获得佣金或服务费。
  • Agent / Skill 市场：用户按需安装旅行、税务、投资、法律、健康等专业能力，形成类似 App Store的能力生态。
  • 基础设施服务：为其他 Agent 提供 Memory、Identity、Authorization、Payment、Credential Vault、Runtime 等底层能力。最值得关注的是“意图入口”的迁移。搜索时代，商业价值来自用户输入的关键词；Agent 时代，用户更可能直接表达“帮我完成什么”。如果 AI 能够从需求识别一路走到筛选、决策和下单，商业价值链就可能从“搜索 → 网站 → 商户”变为“用户 → Personal Agent → 商户”。

八 五个仍未被满足的市场

1. 真正“认识我”的 AI 仍然不存在

今天很多产品都在宣传“AI remembers you”，但绝大多数系统保存的仍是对话摘要、偏好、事实和近期上下文。真正的 Personal Intelligence 需要理解偏好背后的条件、变化和冲突，并持续维护一个会成长、会纠错的个人模型。

2. 个人上下文无法跨 AI 迁移

用户同时使用 ChatGPT、Claude、Gemini、Grok、Manus 时，往往要反复向不同系统解释自己。更合理的结构应当是“Person → Personal Context Layer → Multiple Models / Agents”，而不是为每一家模型分别建立一套人格、记忆和工具连接。

3. Agent 授权仍沿用 App 时代的粗粒度权限

“允许读取 Gmail”对 Agent 而言过于粗糙。真正的委托关系应该能够表达：只看与某项目相关的邮件、可以起草但不能发送、涉及付款必须确认、授权 30 天后失效。未来需要的不是简单 OAuth，而是Delegation Policy。

4. 信任可能成为最大采用瓶颈

聊天机器人答错，通常只是产生一段错误文本；Agent 判断错，却可能发错邮件、买错东西、泄露信息甚至造成经济损失。能力越强，安全、Prompt Injection、防越权、审批、追责和恢复机制的重要性越高。

5. Personal AI 的“所有权”尚未真正解决

用户可能用数年时间让 AI 了解自己的工作、关系、兴趣和人生经历。当平台停止服务、账户被限制或用户希望切换模型时，这套 Personal Intelligence 能否完整迁移？目前多数产品没有把 Personal AI Portability 作为核心设计原则，而这恰恰可能形成下一阶段最强的用户锁定。

九 中国市场：手机、超级 App 与大模型入口可能三路并进

中国个人 AI 市场不会简单复制美国。中国拥有更强的超级 App 生态、移动支付体系、手机厂商和本地生活服务，因此 Personal Agent 更有可能从三类入口同时发展。

  • 手机与操作系统：华为、小米、荣耀、OPPO、vivo 等拥有系统权限、设备入口和本地数据，是最天然的个人 Agent 载体。
  • 超级平台：腾讯、阿里、字节拥有通讯、电商、支付、内容、本地生活等完整服务网络，一旦Agent 与这些服务深度打通，执行能力会远高于孤立的聊天产品。
  • 大模型入口：豆包、Qwen、Kimi、GLM 等会从模型和聊天入口继续向任务执行、长期记忆和Agent 化演进。因此，中国市场更可能形成“手机 OS + 超级 App + 大模型入口”的长期竞合格局，而不是由单一独立Personal Agent 垄断。对创业公司而言，这也意味着必须避免与平台正面复制通用能力，寻找平台不愿做、不能做或天然存在利益冲突的层。

十 创业机会：不是再做一个万能助手

面对 Apple、Google、Meta、OpenAI、华为和小米，创业公司如果只是打造“另一个什么都能做的助手”，长期胜算并不高。大厂拥有更强模型、更多用户、更低获客成本、更丰富的数据和系统权限。真正值得进入的方向主要有三类。

  • 垂直 Personal Agent：围绕投资、法律、医疗、创业、高管事务、家庭管理等高价值角色，把“通用能力”变成“深度理解某一种人生角色”。
  • Personal AI Infrastructure：为其他 Agent 提供 Memory、Identity、Authorization、Payment、 Data、Security 等基础能力。
  • Personal Sovereign AI：不与任何一家模型竞争模型能力，而是建立独立于模型供应商的用户数字主体层，并自由调用最适合的外部 AI 能力。

十一 对 2digime 的战略启示：数字之我 + Agent Orchestration

这轮产业变化对 2digime 最大的意义，不是证明“个人 Agent 很热门”，而是进一步澄清 2digime 应该做什么、尤其不应该做什么。

战略边界

2digime 不做另一个万能 Agent，也不重复建设通用执行能力；通用能力优先调用市场上最强的模型、Agent、Skill 和 Tool。

2digime 真正可能拥有的位置，是“数字之我 + Agent Orchestration”。数字之我 回答“我是谁、我知道什么、我想要什么、我重视什么、我拥有什么、我授权什么”；Agent Orchestration 则负责在具体任务中选择最合适的模型、Agent、Skill 和工具。这一路线与 2digime 现有的产品原则一致：数字之我属于用户、默认私有、平台中立、可审计、可撤销、可迁移；做事能力则优先采用成熟外部能力，而不是自建一套与大模型厂商竞争的通用智能。但也必须警惕另一个极端：数字之我 不能只是一个精致的个人档案。如果“什么都知道、什么都做不了”，用户不会持续使用。执行能力依然是入场门槛，只是 2digime 获得执行能力的方式应当是“整合最强能力”，而不是“重造所有能力”。

十二 未来三年：从能力竞争转向上下文、信任与代理权竞争

2026—2027：Personal Agent 成为消费者 AI 热点

竞争重点仍是执行能力：Browser / Computer Use、Cloud Computer、长期任务、Personal Memory、Proactive AI。大量产品会被包装成“个人 AI 助理”。

2027—2028：通用执行能力逐渐同质化

主流 Agent 都会浏览网页、写邮件、安排行程、购物和调用软件。竞争重心将逐渐从“能不能做”转向“是否懂你、是否可靠、是否方便进入你的真实数字生活”。操作系统和拥有丰富个人数据的平台优势会显著上升。

2028 以后：个人 AI 进入身份、交易和代理权阶段当 Personal Agent 成为日常基础设施后，Agent Identity、Personal Data Ownership、 Authorization、Agent Commerce、Agent-to-Agent Interaction、Portability 等问题会成为核心竞争点。届时最关键的问题可能不再是“哪个 AI 最聪明”，而是“谁控制我的数字代理”。

结语 下一代数字入口，最终是一场“代表谁”的竞争

PC 时代，人通过软件进入数字世界；互联网时代通过网站；移动互联网时代通过 App。AI 时代越来越可能出现新的路径：人先把目标交给 Personal AI，再由 AI 选择模型、工具、服务和商户。一旦这一结构成立，个人 AI 掌握的就不只是“信息入口”，而是更接近“意图入口”。谁能够理解用户真正想完成什么，并持续代表用户完成行动，谁就有机会重新组织软件、搜索、商业和服务。

因此，个人 AI 产业真正值得追问的，不是哪一家 Agent 能更快订一张机票，而是：当 AI 逐渐知道一个人的工作、关系、目标和偏好，并能够代表这个人行动时，这个 AI 究竟属于谁？

今天大多数产品给出的答案仍然是：一个运行在某个平台里的个人助手。另一种可能则是：一个属于用户自己、能够自由选择和调用不同 AI 能力的数字主体。前者争夺的是 Personal Agent，后者争夺的是数字之我。如果未来的 AI 世界由大量模型、Agent、Skill、软件和机器共同组成，那么人最终需要的也许并不是更多 Agent，而是一个始终站在自己这一边、理解自己、代表自己，并能使用整个 AI 世界能力的“数字之我”。这可能正是个人 AI 产业今天仍未被真正占据的位置。
