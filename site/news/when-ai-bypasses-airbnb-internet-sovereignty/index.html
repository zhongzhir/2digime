当 AI 替你绕开 Airbnb：人终于可以拿回互联网主权

从 MBI 体验 Meta Muse 绕开 Airbnb 说起：Agent 可压缩平台中介，但若 Agent 属于巨头，主权只是换房东；兔机米主张数字之我属于人。

兔机米编辑部 · AI 协作整理

一个资深分析师，一年在 Airbnb 上花掉 7000 多美元，又重仓它的股票。按理说，他是最不可能被“AI 要颠覆 OTA”这种说法吓到的人。

但 Meta 的 AI 智能体 Muse 只用了十天，就改写了他的判断。

他让 Muse 结合自己过去的 Airbnb 住宿记录，再翻一遍 Instagram 上收藏的旅行短视频，在两小时车程内挑 5 个住处。Muse 像助理、像老朋友、也像一只不知疲倦的数字眼睛：它读历史、看偏好、筛图片、给理由。等他看中一套农舍，Muse 一分钟内告诉他：不用走 Airbnb，直接找房东订，便宜 60%；卡已经绑好，你点一次确认就行。

那一刻，平台的中介费、排名权、流量入口、信任背书，全被一只 Agent 轻轻撬开。

这位分析师后来清仓 Airbnb，加仓 Meta。市场看到的是一笔交易决定；更深处发生的事是：互联网的主语，正在从“平台”变回“人”。

一、旧互联网：人住在平台里，却不算主人

过去二十年，我们以为“上网”就是打开 App。

想旅游，打开 Airbnb、Booking；想买东西，打开 Amazon；想吃饭，打开 DoorDash；想出门，打开 Uber。平台把供给聚起来，把搜索做出来，把支付接进去，把评价攒起来，再把你锁在里头。

平台并不是坏人。它们确实降低了匹配成本，让全世界的小房东、小商家、独立司机第一次拥有大规模触达用户的能力。但商业逻辑一旦长成，平台就会本能地做四件事：

第一，占有注意力。 首页给你推什么、搜索结果怎么排、限时折扣放哪儿，都不是随机的，而是平台希望你看见的顺序。

第二，占有数据。 你搜过什么、犹豫过什么、复购过什么、退过什么，最后都沉淀在平台服务器里，变成平台的资产、广告系统的燃料。

第三，占有入口。 你本来是想“找个地方住”“买件合适的衣服”，但最后变成“在 Airbnb 里挑”“在 Amazon 里挑”。问题被平台重新定义成了“平台内的问题”。

第四，抽取过路费。 佣金、推广位、竞价排名、会员费、流量税。只要你还亲自刷 App，平台就有理由收这笔钱。

所以旧互联网里，用户表面是“使用者”，实际是被画像的人、被留存的人、被投放的人。你越活跃，平台越值钱；你越懒得比价，平台越舒服。

Airbnb 的护城河曾被总结成两个字：信任；再加两个字：供给。用户不敢跟陌生人直接交易，所以需要平台担保；房东没有独立网站，所以只能依赖平台流量。这个结构非常坚固，直到 Agent 出现。

二、Muse 的真正意义：人第一次有了“数字代理人”

Muse 最吓人的地方，不是“它推荐得准”。

早年的 ChatGPT 也会写攻略。但 Muse 做的是另一件事：它替你行动。

它读你的历史，理解你的口味；它跨应用看 Instagram 收藏，把你“说不清楚的偏好”变成可执行的判断；它在后台比价、联系供给方、算退房改签、绑定支付、等你点头。它不像搜索引擎把一堆链接扔给你，也不像传统 App 把你关在自己的货架里，而像一个新的主体——站在你这边的人。

这也就是《The Synopsis》里说的 Proactive Commerce，主动式电商。

过去商业只有两种模式：

一种是“意图驱动”，你知道要买什么，去搜；

一种是“发现驱动”，你刷着刷着被广告种草。

而 Agent 带来第三种：你不用时刻在线，也不用反复表达需求；你的数字代理人一直在后台理解你、守护你、寻找更优解。你订了 Airbnb，它读邮件发现你还没付款，主动提醒：官网直订省 20%，要我帮你退掉重订吗？

听起来方便，也听起来有点冷。但站在用户立场，这才是正常的：

互联网本来就该帮我省钱、省时间、少被操纵，而不是每天教我怎么在平台里多待十分钟。

MBI 说 Airbnb 可能站到了未来趋势的对立面，并不是说 Airbnb 会一夜倒闭。意思是：当“用户代理”成熟后，平台不再是不可替代的中间人，而可能退化为——供给池、履约方、底层管道。

Booking 还有谷歌流量迁移的经验，有会员体系，有低估值缓冲；Airbnb 估值高、直接流量高、平台叙事强，反而更容易在 Agent 时代被重新定价。

亚马逊也一样。它的广告帝国建立在“人会自动点搜索前三名”之上。可 Agent 不点广告，它只看你的指令：质量优先、同质量比价、再看物流。MBI 让 Muse 评估一件 Meta 广告里的 T 恤，Muse 没护短，反而说这牌子性价比一般，再给替代项。

这时候你才发现：原来平台最怕的不是竞争对手，而是一个真正忠于用户的 AI。

三、但下一个问题更尖锐：如果这个 AI 属于 Meta 呢？

这是整场讨论里最容易被人跳过、却最关键的一层。

Muse 很酷，但 Muse 是 Meta 的。

它读你的 Instagram，连你的社交图谱；它顺手优化 Meta 的电商闭环；它再“客观”，也活在与广告、内容、留存、生态绑定在一起的母体内。

如果未来替我们下单的 Agent 都长在巨头身上，那故事就不是“人拿回互联网”，而是：

平台中介 → 超级平台中介。

以前你被 App 困住；以后你被“平台拥有的 Agent”代表。它说话像你，做事像你，但底层目标仍是平台的：多留数据、多边变现、少让竞品进场。

亚马逊自己就在干这件事。Rufus 在亚马逊里帮你买，Alexa+ 在语音里帮你订，Buy for Me 把外部商品拉回亚马逊结账。亚马逊当然知道 Agentic Commerce 是未来，所以它要的是：Agent 可以有，但必须是我的 Agent。

于是我们撞上了一个分叉口：

一条路：巨头各自养 Agent，用户在不同围墙花园里换管家；

另一条路：每个人拥有一个真正属于自己的数字之我，模型、工具、平台都只是它调用的资源。

兔机米（2digime.com）赌的，是第二条路。

四、兔机米的答案：AI 越强，人越应该是主人

兔机米不把自己做成“又一个超级 App”。它的起点不是聚合商品，也不是抢占时长，而是先回答一个问题：

当 AI 能理解你、替你行动时，这个 AI 到底代表谁？

它的回答拆成三层。

1. 数字之我：不是平台画像，而是“我”的数字主体

平台画像是用来投广告的：你 28 岁、爱露营、客单价 80 到 120、周五晚上容易冲动消费。

数字之我是用来代表你的：你重视安静、讨厌过度装修、出差要离地铁近、周末宁愿多开两小时车也要看山和农舍、对“网红同款”本能警惕。

前者属于平台数据库；后者属于你。

兔机米把长期目标、偏好、资料、共同经历、判断标准沉淀下来，让 AI 从“通用助手”慢慢长成“我的代理人”。它不靠每次从零开始猜你，而是在相处中越来越像你、但不取代你。

2. 超级助手：不是平台客服，而是把事做成的执行层

你不用再学十个 App 的搜索语法。

你说：“帮我安排下周末两小时车程内的住宿，别被平台溢价收割，图片别过度滤镜，退改要清楚。”

兔机米去读历史、接工具、比价格、看评价、对接房源系统、生成方案，最后把决策权交还给你。

它不一定要自己卖房、自己发货、自己派车。它做的是编排：把不断进步的模型、Agent、支付、日历、文件、电商接口连起来，让“AI 的能力”变成“你的能力”。

这正是 Muse 展示出的未来，但所有权不同：

Muse 的能力长在 Meta 里；兔机米的能力长在你这里。

3. 数字主体网络：未来不是平台连平台，而是“我”连“我”

更远的图景不是“所有平台都接一个中央 Agent”，而是每个人的数字之我可以彼此发现、交换信息、协作、议价、提供服务。

A 的数字之我说“我要安静、可带狗、预算 800”；B 的数字之我说“我这有农舍、退改宽松、接受 Agent 预审”。两边不用先把彼此变成 App 用户，也不用先交平台佣金，只要在授权、可验证、可撤回的规则下完成协作。

这时候，Airbnb、Booking、Amazon、Shopify 并不会消失，但它们会从“主人”退回去当“供给方/履约方/工具方”。真正的新入口，是人自己。

五、为什么这篇文章证明了兔机米是对的

很多人看完“体验 Muse 后清仓 Airbnb”，会得出一个结论：AI Agent 要颠覆平台，买 Meta、卖 Airbnb。

但把镜头拉远一点，文章其实给了三层证据：

第一，平台中介价值正在被压缩。

Agent 能抓全网评价，信任不再被单一平台垄断；房东对 AI 说一句“同步挂到 Booking 和 VRBO”，独家供给就松了；用户不再天天打开 Airbnb，直接流量就会掉。旧护城河不是坏了，是被重新定义。

第二，Agent 必然成为新入口。

从“人刷屏”到“Agent 替人比价、预订、下单、退改”，不是科幻。MBI 的农舍案例已经把闭环跑出来了：理解偏好、找到供给、谈出低价、绑定支付、一次确认。

第三，Agent 若不属于用户，主权就只是换了个房东。

Muse 证明趋势，却不自动证明“人自由了”。如果 Agent 属于广告公司、电商巨头、社交平台，它只是把“平台让你看见什么”升级成“Agent 替你决定什么”，而利润仍可能被同一批巨头拿走。

所以兔机米的存在，不是蹭 Agent 热点，而是补上整个叙事里缺的那一块：

主动式电商可以到来，但主语必须是“我”。

没有数字之我，Agent 再聪明，也是别人的销售员。

有了数字之我，Agent 再普通，也站在你这边。

六、重新画一张互联网地图

旧地图是这样的：

平台中心化。

用户 → 平台 → 供给。

数据向上聚，利润向上聚，入口向上聚。

新地图应该是这样的：

人的数字之我中心化。

我 → 我的 Agent → 模型 / 电商 / 出行 / 文件 / 支付 / 内容。

平台变成可被调用的服务，不再天然拥有用户。

对应到那篇报道里的几家公司：

Airbnb / Booking：从“用户直接打开的入口”变成“Agent 可调用的房源与信任数据层”；

Amazon：广告红利承压，必须要么做封闭 Agent，要么向用户 Agent 开放机器可读库存与结账；

Uber / DoorDash：高频低客单、强履约、重人力或自动驾驶变量，冲击来得晚，但“比价 Agent + 自动驾驶车队”也会削掉平台忠诚度；

Meta / Google / Amazon：最有可能拥有“平台级 Agent”，也正因如此，它们和“用户级 Agent”之间会有长期张力。

兔机米不站队任何一家平台。它站队“人”。

七、一句话说清兔机米

如果把互联网比作一座城：

平台说：城门我修的，集市我管的，进来先领我的账号。

大模型公司说：路我通的，马我养的，你出门坐我的车。

兔机米说：你才是城里要生活的人；我帮你记喜好、办琐事、谈价格、留证据，但钥匙、记忆和决定权，都在你手里。

AI 越强，越需要有人替“人”守住边界。

不是让 AI 少做事，而是让 AI 做的事，永远可被人看见、可被人否决、可被人带走。

八、结尾：第三代互联网，不该再由平台加冕

第一代互联网许诺自由：信息平权，任何人可以发任何东西。

第二代互联网走向集中：平台赢家通吃，用户用数据和注意力换便利。

第三代互联网正在开门：Agent 替人行动，界面消失，意图直接变成结果。

但如果第三代只是“平台穿上 Agent 的外衣”，那不过是第二代收租模式的升级版。

兔机米想证明一件更小、也更根本的事：

你不需要先成为某个 App 的活跃用户，才能享受 AI。

你先是你自己，然后才有一个 AI 代表你进入网络。

Muse 让一个投资者清仓 Airbnb；

兔机米想让每一个普通人，在 AI 时代重新做回互联网的主人。

不是被推荐，不是被留存，不是被代理。

是：人理解自己，人授权 Agent，人拥有结果。

这，就是数字之我。

这，就是主动式电商该有的主语。

这，也是兔机米存在的理由。
