你需要准备什么

用已经存在的开放标准

标准越丰富，体验越完整。最低门槛仍接近普通公开网站。

01

文章

公开 HTTPS 页面，加上 RSS / Atom / JSON Feed 和 Feed Autodiscovery。稳定 canonical URL 很重要。

02

视频、音频、图片

在 Feed 里使用 Media RSS 或 JSON Feed 的 attachments；页面上提供 schema.org 的 VideoObject / AudioObject / ImageObject；已知地址可用 oEmbed。

03

用户打开的是你的原文

兔机米发现内容，是为了让人回到你的网站。默认不重新托管版权正文或媒体文件。

最小示例

没有兔机米专有标签

Media RSS

<item>
  <title>示例一集</title>
  <link>https://example.org/watch/ep1</link>
  <media:content url="https://cdn.example.org/ep1.m4v" type="video/mp4" medium="video" duration="720" />
  <media:thumbnail url="https://cdn.example.org/ep1.jpg" />
</item>

JSON Feed attachment

{
  "url": "https://example.org/watch/ep1",
  "title": "示例一集",
  "attachments": [
    { "url": "https://cdn.example.org/ep1.m4v", "mime_type": "video/mp4", "duration_in_seconds": 720 }
  ]
}

完整说明与边界写在 GitHub 的 CONTENT-SUPPLIERS.md，与本页语义一致。
