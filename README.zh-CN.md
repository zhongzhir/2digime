# 2digime — Digital Me

[English](README.md) | [简体中文](README.zh-CN.md)

**Digital Me** 是由你控制的个人数字之我：代表你、为你做事，也可以与另一个数字之我协作。它调度真实的改代码能力和你已连接的模型，而不是再包一层聊天机器人。

> **当前阶段：实验预览。** 不是成品，也不是已达市场标准的产品。仓库提前公开，便于试用与评阅。

## 它是什么

不是通用聊天助手。系统里只有一份你已确认的本人记录；模型是能力，不是决策者。能力未连接时会停下来说明，不会假装成功。做成并采用的事会回到数字之我，而不会悄悄改写「你是谁」。

## 现在能做什么

- **对话**：交流；需要时可以转为任务。已确认的本人事实会被遵守，没有的不会编造。
- **做事**：说明任务、添加项目文件夹、确认范围后，用本机改代码工具或已连接的模型改文件或产出成果，独立检查后再由你采用。
- **数字之我**：查看并继续构建已确认的本人内容。
- **协作（实验）**：连接另一台电脑上的数字之我，发现机会、提出意向。还不能当作完整的远程交活，也不能传大文件、多人协作或对外自动承诺。

## 试用（Windows 预览）

从 [Releases](https://github.com/zhongzhir/2digime/releases) 下载 **Windows x64** 预览 ZIP：

1. 解压到任意文件夹。
2. 双击 `DigitalMeV2.exe`，无需安装。
3. 先到 **设置** 连接模型（使用你自己的密钥）。未连接时，对话和做事不会假装已经完成。
4. 卸载 = 删除该文件夹。密钥只留在这台电脑上。

包未签名。系统可能提示风险，请仅在信任来源时继续。

## 现阶段

实验预览。对话 / 做事 / 采用 / 成长这条主路径已在集成基线上通过真机验收。协作仍是实验。不是全自动代理，也不是成熟协作网络。本基线有少量已知测试失败，仓库内有说明。

更细的架构见 [docs/architecture](docs/architecture/)。

