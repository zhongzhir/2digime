# 2digime（兔机米）

[English](README.md) · [中文](README.zh-CN.md)

**属于你的数字之我。**

你只需要告诉兔机米想做什么。它会理解你的目标，并在需要时自行寻找和组织合适的 AI 能力完成任务。在持续的对话、做事、选择和连接世界过程中，它会不断了解你、接受你的纠正，成长为越来越接近你的数字之我。

> **Public Alpha** · 早期试用 · 开源 · **先支持 Windows x64**  
> 不是生产就绪，也不宣称已经做完所有能力。

---

## 属于我 · 能做事 · 连接世界

三者是同一个主体的伸展，不是三个产品。

### 属于我

全系统只有一份数字之我。它会在对话和真实做事中学习；每条认识都有来源。你可以打开「数字之我」查看、纠正或删除。你亲口确认的内容具有最高权威。

长期目标是持续逼近真人之我，而不是一次性做成静态 Profile。它不会完美复制你，也不会自动知道一切。

### 能做事

你不需要先自己搭建一套 AI 工具链。

1. 在同一段对话里直接说出目标。  
2. 兔机米判断需要什么能力。  
3. 调用，或自行获得，成熟的 AI / Agent / Tool。  
4. 在你授权的范围内执行。  
5. 检查结果。  
6. 回到同一个对话。

日常入口只有「与兔机米」。做事不是另一扇门，也不是「先把这句话转成任务」。

已经真实验证的例子：在编程任务中，兔机米已经能够在没有预装 Coding Agent 的情况下自行获得专业编程能力，并完成真实修改和测试。

### 连接世界

每个 2digime 都可以成为属于真人的智能网络节点。

已经验证的核心：Relay 只提供候选和传输；不拥有用户画像；不做最终个性化推荐。同一候选池由每个数字之我自己判断；不同数字之我可以形成不同、可解释的信息选择。你可以通过改变自己的数字之我，重新定义选择方式。

**把「我该看到什么」的最终选择权，从中心平台算法重新交还给用户自己的数字主体。**

Relay、搜索、存储、模型等中间服务不会消失——它们作为网络服务商存在，而不天然成为用户选择和分发的主人。

当前 Alpha **没有**开放完整内容 Feed、关注/订阅、大规模开放网络、交易或支付。也没有 Computer Use。试用界面里找不到「网络」页，这是刻意的。

## 为什么是 2digime

多数 AI 产品是通用模型，外加平台替你决定该看见什么。2digime 的长期差异是：

- **数字之我** — 身份、记忆和纠正属于你，留在你的电脑上。  
- **AI 能力** — 接入成熟模型和 Agent，而不是自研去和它们比编程、搜索或 Computer Use。  
- **数字主体网络** — 候选可以由网络提供；**个性化选择留在你自己的数字之我。**

---

## 架构原则（极短）

- **AI First**：理解和选用能力交给模型，而不是关键词路由。  
- **能接不造**：优先成熟 Agent / Tool / 服务。  
- **本地优先、用户所有**：密钥和数字之我在本机。  
- **平台中立**：能力提供方可替换。  
- **Relay 是服务商，不是推荐权威。**  
- **开源**：[Apache-2.0](LICENSE)。
